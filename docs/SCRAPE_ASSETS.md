# Artwork

`assets/` contains the approved BlissOScera branding set.

| File | Intended use |
|---|---|
| `app-icon.png` | launcher / GUI icon |
| `marquee.png` | EmulationStation marquee |
| `scrape-wheel.png` | game details / wheel-style artwork |
| `box-art.png` | optional vertical box art |
| `about-screen.png` | project/About promotional artwork |
| `logo-primary.png` | README, GitHub and documentation |
| `branding-showcase.png` | complete approved design board |

The current files are extracted from the approved design board and can be
replaced later by clean master renders without changing filenames.
